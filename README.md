# Capture Two

A Python-based clone of Capture One, the professional image editing application.

## Overview

This repository aims to recreate core image editing functionality from Capture One using pure Python scripts. No GUI framework - just Python code for processing and manipulating images.

## Features (Planned)

- RAW image processing
- Exposure and contrast adjustments
- Color grading and white balance
- Crop and rotate operations
- Export to common formats (JPEG, PNG, TIFF)
- Batch processing capabilities

## Requirements

- Python 3.8+
- Pillow (PIL)
- NumPy
- rawpy (for RAW processing)

## Usage

```bash
python capture_two.py --input image.raw --output edited.jpg
```
